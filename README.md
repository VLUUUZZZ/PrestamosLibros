# Préstamos de Libros

REST API for managing library book loans, built with **Spring Boot** and **MySQL**.

> **Status: work in progress.** The data model is defined; controllers, services, repositories and error handling are being implemented.

## Tech Stack

- Java 21
- Spring Boot 4 (Web MVC, Data JPA, Validation)
- MySQL
- springdoc-openapi (Swagger UI)
- Lombok
- Maven

## Data Model

```
Lector 1 ──── * Prestamo * ──── 1 Libro
```

| Entity | Fields |
|---|---|
| **Lector** (reader) | `id`, `nombre`, `activo`, `membresiaPremium` |
| **Libro** (book) | `id`, `titulo`, `ejemplaresDisponibles` |
| **Prestamo** (loan) | `id`, `lector`, `libro`, `fechaPrestamo`, `fechaDevolucionMaxima`, `estado` |

A loan can be `Prestado` (on loan), `DEVUELTO` (returned) or `VENCIDO` (overdue).

## Project Structure

The project lives in the `prestamosLibros/` folder.

```
src/main/java/mx/edu/utez/prestamosLibros
├── Controller   REST endpoints for readers, books and loans
├── service      Loan business logic
├── repository   Spring Data JPA repositories
├── models       JPA entities and enums
├── dto          Request objects
└── exceptions   Custom exceptions and global error handler
```

## Getting Started

Requires MySQL running on `localhost:3306` with user `root` / password `root`. The `prestamos_libros` database is created automatically and tables are generated by Hibernate.

```bash
cd prestamosLibros
./mvnw spring-boot:run
```

The application runs at `http://localhost:33666`.
